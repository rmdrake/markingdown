# Markdown Editor

A lightweight, single-file Markdown editor that provides a real-time preview, multiple color schemes, and a seamless writing experience directly in your web browser.

## 🚀 Features

- **Real-time Preview**: See your Markdown rendered instantly as you type.
- **Multiple Themes**: Choose from various color schemes like *Ocean*, *Desert*, and *Forest*, or stick to the default *Space* theme.
- **Dark Mode Support**: Toggle between light and dark modes easily. Themes are saved in your browser via `localStorage` and can respect your system preferences.
- **File Management**: Open existing `.md` or `.txt` files and save your work locally with ease.
- **Find & Replace**: Quickly navigate and edit your text with the built-in find and replace tool.
- **Responsive Design**: Works beautifully on desktops, tablets, and mobile devices.
- **Zero Dependencies (mostly)**: Everything is contained in a single HTML file, using only `marked.js` via CDN for rendering.
- **Accessible**: Built with accessibility in mind, featuring ARIA labels and keyboard-friendly interactions.

## 🛠️ Tech Stack

- **HTML5**
- **CSS3** (including CSS Variables and Flexbox)
- **Vanilla JavaScript**
- **[Marked.js](https://github.com/markedjs/marked)** (Markdown parser)

## 📖 Usage

No installation required!

1. Download the `markingdown.html` file.
2. Open it in any modern web browser (Chrome, Firefox, Safari, or Edge).
3. Start writing your Markdown!

### Key Actions
- **Open**: Load a local file to edit.
- **Save**: Save your current work.
- **Save As**: Save your work with a new filename.
- **Find**: Opens the find and replace panel.
- **Theme Toggle**: Switch between light and dark modes.

## 🎨 Themes

You can customize your writing environment with several built-in schemes:
- 🌌 **Space** (Default)
- 🌊 **Ocean**
- 🏜️ **Desert**
- 🌲 **Forest**
